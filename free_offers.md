# AWS Free Tier Offers

> **Important:** The traditional 12-month free tier applies only to AWS accounts created **before July 15, 2025**.
> Accounts created after that date receive a new program: up to **$200 in credits** + a **6-month free plan**
> (expires after 6 months or when credits run out, whichever comes first).
> See the [official announcement](https://aws.amazon.com/blogs/aws/aws-free-tier-update-new-customers-can-get-started-and-explore-aws-with-up-to-200-in-credits/) for details.

---

## 12 Months Free (accounts created before July 15, 2025)

| Service | Monthly Free Tier Limit | Primary Use Case |
|---|---|---|
| Amazon EC2 | 750 hours (t2.micro or t3.micro) | Virtual servers (Compute) |
| Amazon S3 | 5 GB storage, 20k GET, 2k PUT requests | Object/file storage |
| Amazon RDS | 750 hours (db.t2.micro / db.t3.micro — MySQL, PostgreSQL, MariaDB) + 20 GB SSD + 20 GB backups | Relational databases |
| Amazon API Gateway | 1 million REST API calls | API creation and management |
| Amazon EBS | 30 GB SSD (gp2 or gp3) | Block storage for EC2 instances |
| Amazon EFS | 5 GB storage | Shared file system |
| Elastic Load Balancing | 750 hours shared + 15 GB data processing | Load balancing between servers |
| Amazon Comprehend | 50,000 text units per API | Natural language processing (NLP) |
| Amazon Lex | 10,000 text requests + 5,000 voice requests | Chatbot creation (like Alexa) |
| Amazon Polly | 5 million characters (Standard voices) / 1 million characters (Neural voices) | Realistic text-to-speech |
| Amazon Transcribe | 60 minutes of audio | Speech-to-text conversion |
